# 🤖 Cybertron WhatsApp Bot

A Transformers-themed WhatsApp bot powered by Baileys.

## Features
- 🔐 **AUTO-BOTS Pairing Protocol** - Custom pairing code
- ⚡ **Transformers Theme** - Autobot & Decepticon aesthetics
- 👥 **Role-Based Access** - Owner, Dev, Sudo, Standard users
- 🎭 **Random Autobot Selection** - Different bot personality each session
- 📱 **Baileys Integration** - Full WhatsApp API support

## Installation

```bash
npm install
```

## Configuration

Edit `config.js` and set your phone number:

```javascript
ownerNumber: "YOUR_PHONE_NUMBER"
```

## Running

```bash
npm start
```

Scan the QR code with WhatsApp to authenticate.

**Pairing Code:** `AUTO-BOTS`
